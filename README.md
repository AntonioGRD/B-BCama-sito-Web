# B&B CaMa - Gragnano (Sito Web Ufficiale)

Sito web moderno e responsive per il **B&B CaMa**, situato nel cuore di Gragnano (NA), in posizione strategica tra Pompei, Sorrento e la Costiera Amalfitana.

Punteggio medio su Booking.com: **9.5 / 10 (Eccezionale)**.

---

## 🌟 Caratteristiche Principali

- **Design & UI**: Sviluppato con HTML5 semantico, Tailwind CSS, Google Fonts (*Outfit* & *Playfair Display*) e icone Lucide.
- **Chi Siamo & Informazioni**: Presentazione della struttura (5° piano con vista sui Monti Lattari, terrazza panoramica e colazione inclusa).
- **Galleria Camere**: Schede dettagliate per le camere con tariffe, servizi inclusi e selezione rapida.
- **Sistema di Prenotazione Dinamico**:
  - Datepicker automatico con validazione date (check-in da oggi/domani, orario di check-in 17:00 e check-out 10:30).
  - Calcolo automatico in tempo reale delle notti e del totale stimato.
  - Modale di riepilogo con invio rapido su **WhatsApp** (+39 344 718 6581) ed **Email**.
- **Posizione & Distanze**: Indicazioni e distanze reali per Scavi di Pompei (10 km), Sorrento (18 km), Marina di Puolo (24 km), Vesuvio (28 km) e Aeroporto di Napoli (33 km).
- **Pronto per GitHub Pages**: Nessun build complessa richiesta, apribile direttamente su qualsiasi browser o hosting statico.

## 🚀 Come pubblicare su GitHub e attivare GitHub Pages

1. **Crea un nuovo repository su GitHub** (es. `bb-cama-website`).
2. **Collega il repository locale e fai il push**:
   ```bash
   git remote add origin https://github.com/TUO-USERNAME/bb-cama-website.git
   git branch -M main
   git push -u origin main
   ```
3. **Attiva GitHub Pages (Opzionale)**:
   - Vai nelle impostazioni del repository su GitHub: `Settings` > `Pages`.
   - Sotto **Branch**, seleziona `main` e la cartella `/ (root)`.
   - Clicca su **Save**: il sito sarà online e consultabile gratuitamente da chiunque!
